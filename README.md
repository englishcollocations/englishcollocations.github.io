# English Collocations - Interactive Learning Platform 🎧📚

A modern, responsive web application for learning English collocations through 50 interactive audio lessons.

## ✨ Features

### 🎵 Audio Learning
- **50 Audio Lessons**: Complete collocation lessons with clear pronunciation
- **Advanced Audio Player**: Play/pause, speed control, volume adjustment
- **Progress Tracking**: Visual progress bar and lesson completion tracking
- **Keyboard Shortcuts**: Space (play/pause), arrows (navigation), M (mark complete)

### 📱 Progressive Web App (PWA)
- **Offline Support**: Works without internet connection after first load
- **Install on Device**: Add to home screen on mobile/desktop
- **Native App Feel**: Standalone mode without browser UI
- **Cross-Platform**: Works on iOS, Android, Windows, Mac, Linux

###  Note-Taking System
- **Lesson Notes**: Personal notes for each lesson with auto-save
- **Character Counter**: Track note length
- **Local Storage**: Notes saved locally on your device
- **Search & Filter**: Find specific lessons quickly

### 🎨 Modern UI/UX
- **Responsive Design**: Perfect on mobile, tablet, and desktop
- **Tailwind CSS**: Modern, clean interface
- **Dark/Light Themes**: Automatic theme adaptation
- **Touch-Friendly**: Optimized for touch interactions

## 🚀 Quick Start

1. **Open the Website**: Visit the hosted URL
2. **Install as App**: Click "Add to Home Screen" for mobile app experience
3. **Start Learning**: Choose any lesson and begin listening
4. **Track Progress**: Mark lessons complete and add personal notes
5. **Work Offline**: App works without internet after first load

## 📱 Installation

### Mobile (iOS/Android)
1. Open in Safari (iOS) or Chrome (Android)
2. Look for "Add to Home Screen" option
3. Follow the prompts to install
4. Launch from home screen like a native app

### Desktop (Chrome/Edge/Firefox)
1. Open in supported browser
2. Look for install icon in address bar
3. Click to install as desktop app
4. Launch from start menu/applications

## 🎯 How to Use

### Audio Player
- **Play/Pause**: Click play button or press Space
- **Navigation**: Use previous/next buttons or arrow keys
- **Speed Control**: Adjust playback speed (0.5x to 2x)
- **Volume**: Use slider or up/down arrow keys
- **Progress**: Click progress bar to jump to specific time

### Progress Tracking
- **Mark Complete**: Click green checkmark or press 'M'
- **View Progress**: See completion percentage in header
- **Search Lessons**: Type in search box to filter
- **Reset Progress**: Clear all progress if needed

### Note-Taking
- **Add Notes**: Click in notes area and start typing
- **Auto-Save**: Notes automatically saved every 2 seconds
- **Manual Save**: Click save button for immediate save
- **Character Limit**: Track note length with live counter

## 🔧 Troubleshooting

### Audio Not Playing
- Check device volume and browser permissions
- Try refreshing the page
- Ensure audio files are properly loaded

### App Not Installing
- Use supported browser (Chrome, Safari, Edge)
- Check if PWA installation is enabled
- Try refreshing and looking for install prompt

### Notes Not Saving
- Check browser local storage permissions
- Ensure JavaScript is enabled
- Try manual save button if auto-save fails
